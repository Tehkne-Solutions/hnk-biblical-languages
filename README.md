# HNK Biblical Languages

Curso gamificado e comparativo de **Esperanto + Hebraico Bíblico + Grego Koiné**, construído a partir do DNA pedagógico SimpleWay, mas mantido como produto e repositório independentes.

## Cadeia pedagógica

```text
Português → Esperanto → Hebraico Bíblico + Grego Koiné → Escrituras → Exegese linguística responsável
```

## Contrato editorial

```text
texto-fonte → transliteração → lema/gloss → morfologia → tradução literal → tradução natural → nota → interpretação
```

Morfologia, tradução e conclusão teológica permanecem camadas separadas.
